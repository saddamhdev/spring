In **Spring / Spring Boot**, *Configuration annotations* are used to **define and control how Spring creates and manages beans and application configuration**.

Since you work with **Spring Boot microservices**, these annotations are used frequently in configuration classes (like Redis config, Kafka config, Security config, etc.).

Below are the **most important configuration annotations**.

---

# 1. `@Configuration`

This marks a **class as a configuration class** that contains bean definitions.

Spring will read this class and register beans into the **ApplicationContext**.

### Example

```java
@Configuration
public class AppConfig {

    @Bean
    public MyService myService() {
        return new MyService();
    }
}
```

### What happens

Spring creates:

```
MyService → Bean → Spring Container
```

### Important

`@Configuration` is a **specialized @Component**.

So Spring will automatically scan it.

---

# 2. `@Bean`

Defines a **bean manually** inside a configuration class.

Used when you want **full control over object creation**.

### Example

```java
@Configuration
public class KafkaConfig {

    @Bean
    public KafkaTemplate<String, String> kafkaTemplate() {
        return new KafkaTemplate<>();
    }
}
```

### When to use

When configuring things like:

* Kafka
* Redis
* HttpClient
* Security
* Third-party libraries

---

# 3. `@EnableConfigurationProperties`

Used to **bind application.yml / properties into a class**.

### Example

### application.yml

```yaml
app:
  name: MyApp
  timeout: 5000
```

### Properties Class

```java
@ConfigurationProperties(prefix = "app")
public class AppProperties {

    private String name;
    private int timeout;
}
```

### Config Class

```java
@Configuration
@EnableConfigurationProperties(AppProperties.class)
public class AppConfig {
}
```

Now Spring automatically maps:

```
app.name → name
app.timeout → timeout
```

---

# 4. `@ConfigurationProperties`

Used to map **YAML properties → Java object**.

### Example

```java
@ConfigurationProperties(prefix = "redis")
public class RedisProperties {

    private String host;
    private int port;
}
```

### YAML

```yaml
redis:
  host: localhost
  port: 6379
```

Spring automatically loads values.

You use this a lot in **microservice configuration**.

---

# 5. `@Import`

Used to **import another configuration class**.

### Example

```java
@Configuration
@Import(RedisConfig.class)
public class AppConfig {
}
```

Equivalent to saying:

```
Include RedisConfig in this configuration
```

Useful for **modular configuration**.

---

# 6. `@PropertySource`

Used to **load external property files**.

### Example

```java
@Configuration
@PropertySource("classpath:custom.properties")
public class AppConfig {
}
```

Spring will read:

```
custom.properties
```

---

# 7. `@ComponentScan`

Tells Spring **where to scan for components**.

### Example

```java
@Configuration
@ComponentScan("com.example.service")
public class AppConfig {
}
```

Spring will scan:

```
@Service
@Repository
@Component
@Controller
```

---

# 8. `@Conditional` (Advanced)

Used to create beans **only if a condition is true**.

Example condition types:

* Property condition
* Class condition
* Bean condition
* Missing bean condition

Example:

```java
@Bean
@ConditionalOnProperty(name = "redis.enabled", havingValue = "true")
public RedisService redisService() {
    return new RedisService();
}
```

Bean will be created **only if property is true**.

---

# 9. `@AutoConfiguration` (Spring Boot 3+)

Used by **Spring Boot internally** to automatically configure things.

Example:

```
KafkaAutoConfiguration
RedisAutoConfiguration
DataSourceAutoConfiguration
```

Example:

```java
@AutoConfiguration
public class RedisAutoConfig {
}
```

---

# 10. `@EnableAutoConfiguration`

Tells Spring Boot to **automatically configure beans** based on dependencies.

Example:

If dependency exists:

```
spring-boot-starter-data-redis
```

Spring automatically configures:

```
RedisConnectionFactory
RedisTemplate
```

---

# 11. `@ConditionalOnMissingBean`

Create bean **only if another bean does not exist**.

### Example

```java
@Bean
@ConditionalOnMissingBean
public RedisService redisService() {
    return new RedisService();
}
```

If another `RedisService` exists → Spring **won't create this one**.

---

# 12. `@ConditionalOnClass`

Create bean **only if a class exists in classpath**.

Example:

```java
@Bean
@ConditionalOnClass(name = "org.apache.kafka.clients.producer.KafkaProducer")
public KafkaService kafkaService() {
    return new KafkaService();
}
```

If Kafka dependency exists → bean created.

---

# Real Example (Like your Kafka Config)

Your code probably looks like:

```java
@AutoConfiguration
@ConditionalOnClass(KafkaTemplate.class)
@ConditionalOnProperty(prefix = "kafka", name = "enabled", havingValue = "true")
@EnableConfigurationProperties(KafkaProperties.class)
public class KafkaAutoConfiguration {

    @Bean
    @ConditionalOnMissingBean
    public KafkaProducerService kafkaProducerService() {
        return new KafkaProducerService();
    }
}
```

Meaning:

```
Load configuration automatically
Only if Kafka dependency exists
Only if kafka.enabled=true
Load KafkaProperties
Create bean only if missing
```

---

# Summary

| Annotation                       | Purpose                    |
| -------------------------------- | -------------------------- |
| `@Configuration`                 | Define configuration class |
| `@Bean`                          | Create bean manually       |
| `@ConfigurationProperties`       | Bind YAML to class         |
| `@EnableConfigurationProperties` | Enable properties binding  |
| `@Import`                        | Import another config      |
| `@PropertySource`                | Load property file         |
| `@ComponentScan`                 | Scan components            |
| `@Conditional`                   | Conditional bean creation  |
| `@ConditionalOnClass`            | Load if class exists       |
| `@ConditionalOnMissingBean`      | Load if bean missing       |
| `@ConditionalOnProperty`         | Load if property enabled   |
| `@AutoConfiguration`             | Spring Boot auto config    |
