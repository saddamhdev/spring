Spring Boot-এ **Conditional annotations** ব্যবহার করা হয় যাতে নির্দিষ্ট condition পূরণ হলেই bean / configuration load হয়। এটি বিশেষভাবে **AutoConfiguration, starter libraries, microservices configuration**-এ খুব গুরুত্বপূর্ণ।

আমি প্রধান conditional annotations গুলো **category অনুযায়ী** ব্যাখ্যা করছি।

---

# 1️⃣ Property based conditional

## `@ConditionalOnProperty`

সবচেয়ে বেশি ব্যবহৃত।

YAML property দেখে bean create করবে।

```java
@ConditionalOnProperty(prefix = "kafka-service-log", name = "enabled", havingValue = "true")
```

YAML:

```yaml
kafka-service-log:
  enabled: true
```

Condition:

```
enabled = true → bean create
enabled = false → bean create হবে না
```

Example use case:

```
feature toggle
logging enable/disable
security provider enable/disable
```

---

# 2️⃣ Class based conditional

## `@ConditionalOnClass`

যদি class classpath-এ থাকে।

```java
@ConditionalOnClass(KafkaTemplate.class)
```

Condition:

```
spring-kafka dependency আছে → configuration load
dependency নেই → skip
```

Use case:

```
starter libraries
optional dependencies
```

---

## `@ConditionalOnMissingClass`

Opposite condition।

```java
@ConditionalOnMissingClass("org.apache.kafka.KafkaTemplate")
```

Condition:

```
Kafka library নেই → configuration load
```

---

# 3️⃣ Bean based conditional

## `@ConditionalOnBean`

যদি container-এ already bean থাকে।

```java
@ConditionalOnBean(KafkaTemplate.class)
```

Condition:

```
KafkaTemplate bean exist → bean create
```

Use case:

```
dependent bean creation
```

---

## `@ConditionalOnMissingBean`

যদি bean না থাকে।

```java
@ConditionalOnMissingBean(KafkaTemplate.class)
```

Condition:

```
KafkaTemplate exist → create হবে না
KafkaTemplate নেই → create হবে
```

Use case:

```
override support
custom configuration
```

---

# 4️⃣ Resource based conditional

## `@ConditionalOnResource`

যদি resource exist করে।

```java
@ConditionalOnResource(resources = "classpath:application.yml")
```

Condition:

```
file exist → load
```

Use case:

```
configuration files
external resources
```

---

# 5️⃣ Web environment conditional

## `@ConditionalOnWebApplication`

Web application হলে run হবে।

```java
@ConditionalOnWebApplication
```

Condition:

```
Spring MVC / WebFlux app
```

Use case:

```
web configuration
controllers
filters
```

---

## `@ConditionalOnNotWebApplication`

Web app না হলে run হবে।

```
CLI application
batch application
```

---

# 6️⃣ Expression based conditional

## `@ConditionalOnExpression`

SpEL expression evaluate করে।

```java
@ConditionalOnExpression("${feature.enabled:true}")
```

Example:

```
feature.enabled=true → load
```

---

# 7️⃣ Custom conditional

## `@Conditional`

নিজের condition লিখতে পারো।

Example:

```java
@Conditional(MyCustomCondition.class)
```

Custom class:

```java
public class MyCustomCondition implements Condition {

    @Override
    public boolean matches(ConditionContext context,
                           AnnotatedTypeMetadata metadata) {

        return true;
    }
}
```

Use case:

```
complex runtime condition
environment detection
custom logic
```

---

# 8️⃣ Environment conditional

## `@Profile`

Environment based।

```java
@Profile("dev")
```

Condition:

```
spring.profiles.active=dev
```

Example:

```
dev database
test configuration
prod configuration
```

---

# 9️⃣ Combined conditional example

Production auto configuration example:

```java
@AutoConfiguration
@ConditionalOnClass(KafkaTemplate.class)
@ConditionalOnProperty(prefix="kafka-service-log", name="enabled", havingValue="true")
public class KafkaLogAutoConfiguration {
}
```

Condition:

```
1️⃣ Kafka dependency আছে
2️⃣ kafka-service-log.enabled=true
```

# 🔟 Conditional annotations summary

| Annotation                      | Purpose              |
| ------------------------------- | -------------------- |
| @ConditionalOnProperty          | YAML property check  |
| @ConditionalOnClass             | dependency present   |
| @ConditionalOnMissingClass      | dependency absent    |
| @ConditionalOnBean              | bean exists          |
| @ConditionalOnMissingBean       | bean missing         |
| @ConditionalOnResource          | file/resource exists |
| @ConditionalOnWebApplication    | web app              |
| @ConditionalOnNotWebApplication | non-web app          |
| @ConditionalOnExpression        | SpEL condition       |
| @Conditional                    | custom logic         |
| @Profile                        | environment profile  |
