তুমি সম্ভবত **`On` এবং `Missing` ধরনের Conditional annotations** বুঝতে চাও (যেমন `@ConditionalOnBean`, `@ConditionalOnMissingBean` ইত্যাদি)। এগুলো Spring Boot-এর **Auto-configuration system**-এ খুব গুরুত্বপূর্ণ।

আমি সহজভাবে explain করছি।

---

# 1️⃣ `On` vs `OnMissing` — মূল ধারণা

| Type        | Meaning                                      |
| ----------- | -------------------------------------------- |
| `On`        | যদি কিছু **exist করে** তাহলে bean create হবে |
| `OnMissing` | যদি কিছু **না থাকে** তাহলে bean create হবে   |

---

# 2️⃣ `@ConditionalOnBean`

যদি container-এ bean already থাকে।

```java
@ConditionalOnBean(KafkaTemplate.class)
```

Meaning:

```
KafkaTemplate bean exist → create this bean
KafkaTemplate bean নেই → create হবে না
```

Example:

```java
@Bean
@ConditionalOnBean(KafkaTemplate.class)
public KafkaLogService kafkaLogService() {
    return new KafkaLogService();
}
```

Flow:

```
KafkaTemplate exist
       │
       ▼
KafkaLogService create
```

---

# 3️⃣ `@ConditionalOnMissingBean`

যদি bean না থাকে।

```java
@ConditionalOnMissingBean(KafkaTemplate.class)
```

Meaning:

```
KafkaTemplate bean নেই → create
KafkaTemplate bean আছে → create হবে না
```

Example:

```java
@Bean
@ConditionalOnMissingBean(KafkaTemplate.class)
public KafkaTemplate kafkaTemplate() {
    return new KafkaTemplate(...);
}
```

Use case:

```
default bean provide
```

User চাইলে override করতে পারে।

---

# 4️⃣ `@ConditionalOnClass`

যদি classpath-এ class থাকে।

```java
@ConditionalOnClass(KafkaTemplate.class)
```

Meaning:

```
spring-kafka dependency আছে → config load
dependency নেই → skip
```

Example:

```
starter library
```

---

# 5️⃣ `@ConditionalOnMissingClass`

Opposite condition।

```java
@ConditionalOnMissingClass("org.apache.kafka.KafkaTemplate")
```

Meaning:

```
Kafka library নেই → configuration load
```

---

# 6️⃣ `@ConditionalOnProperty`

Property based condition।

```java
@ConditionalOnProperty(
    prefix = "kafka-service-log",
    name = "enabled",
    havingValue = "true"
)
```

Meaning:

```
enabled=true → bean create
enabled=false → skip
```

---

# 7️⃣ Real example (তোমার code)

তোমার code:

```java
@Bean
@ConditionalOnMissingBean(KafkaTemplate.class)
public KafkaTemplate<String, Object> kafkaLogTemplate(...)
```

Meaning:

```
KafkaTemplate bean already exist → skip
KafkaTemplate bean নেই → create
```

Benefit:

```
User custom KafkaTemplate use করতে পারবে
```

---

# 8️⃣ Real Spring Boot pattern

Spring Boot auto configuration এ সাধারণত এই combination থাকে:

```
@ConditionalOnClass
@ConditionalOnProperty
@ConditionalOnMissingBean
```

Example:

```java
@AutoConfiguration
@ConditionalOnClass(KafkaTemplate.class)
@ConditionalOnProperty(prefix="kafka-service-log", name="enabled", havingValue="true")
public class KafkaLogAutoConfiguration {
}
```

Condition:

```
Kafka dependency আছে
AND
kafka-service-log.enabled=true
```

---

# 9️⃣ Common `On` / `Missing` annotations

| Annotation                   | Meaning        |
| ---------------------------- | -------------- |
| `@ConditionalOnBean`         | bean exist     |
| `@ConditionalOnMissingBean`  | bean missing   |
| `@ConditionalOnClass`        | class exist    |
| `@ConditionalOnMissingClass` | class missing  |
| `@ConditionalOnProperty`     | property match |
| `@ConditionalOnResource`     | resource exist |

---

# 🔟 Simple rule

```
On = check existence
Missing = check absence
```

Example:

```
OnBean → bean আছে
OnMissingBean → bean নেই
```

---

# 11️⃣ Why important

এই annotations ব্যবহার করে:

```
starter libraries
auto configuration
feature toggle
optional dependencies
override support
```

সব control করা যায়।

---

✅ Example architecture:

```
AutoConfiguration
       │
       ├ OnClass → dependency check
       ├ OnProperty → feature toggle
       └ OnMissingBean → allow override
```
